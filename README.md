## Aplikasi To-Do List

## Deskripsi

Aplikasi sederhana berbasis React Typescript dengan Framework Next JS untuk mencatat tugas harian.

## Fitur

- Tambah Tugas
- Tandai Tugas Selesai
- Hapus Tugas

## Struktur Folder

- app/ (ini untuk folder core)
- features ()
- public
- shared
- views ()
  /to-do/ui/ToDoListPage.tsx views utama
- widgets

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
